# Shared Resources

Common resources used by both legacy and client implementations.

## Structure
- `config/` - Shared configuration schemas and defaults
- `docs/` - Cross-platform documentation
- `test-data/` - Reference test data and samples

## Contents

### Configuration
- Common configuration validation schemas
- Default settings used by both implementations
- Migration configuration mappings

### Test Data
- `golden-pgns/` - Reference PGN files for validation
- `sample-configs/` - Test configuration files
- Reference outputs from legacy system

## Usage
Both legacy and client implementations should reference these shared resources for consistency during migration.
